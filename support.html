Set up step by step

  1. Install the NDI plugin in OBS. Download DistroAV and install it as described on the plugin's page, together with the NDI Runtime. Then restart OBS.
  2. Turn on NDI output in OBS. Tools → DistroAV NDI Settings (NDI Output Settings in older versions) → check Main Output. OBS now sends the program picture over your local network.
  3. Pick OBS on the iPad. Open Overlay Pencil and tap Choose Source, or the gear icon. The first time, the iPad asks for local network access — choose Allow, otherwise the app can't find OBS. Under Network Sources, pick the OBS output.
  4. Add the drawing layer in OBS. In your scene, add an NDI Source and select IPAD-NAME (Overlay Pencil). Put it above the picture you send to the iPad and stretch it to fill the frame.
  5. Set the latency mode to Normal. In the properties of that NDI source, set Latency Mode to Normal. The drawing has a transparent background, and the Lowest mode drops transparency.
  6. Draw something. The strokes should appear in OBS on a transparent background, on top of the picture.

Settings worth knowing

Output to OBS → Resolution

720p or 1080p for the drawing layer. Fewer pixels to encode means smoother output; on thin strokes the difference is hard to see.

Incoming Video Quality

Full or Low Bandwidth for the picture you see on the iPad. It only affects your preview — the drawing goes back to OBS at full sharpness either way.

Grid

Tap the grid icon in the toolbar to show or hide it, touch and hold to pick a type: rule of thirds, squares, center or safe area. In Settings → Grid you choose whether viewers see it too (Send Grid to OBS).

Snapshots

The camera button saves the current frame with your drawing. Later you go through them and either save each to Photos or discard it.

Free version and Premium

The free version has an “Overlay Pencil” watermark across the frame, on the iPad and in OBS. After 2 minutes from launch it covers the stage; restart the app to start a new session.

Premium removes both limits. It's a one-time in-app purchase: gear icon → Premium — No Limits. Bought it on another iPad or reinstalled the app? Use Restore Purchase on the same screen.

Troubleshooting

The source list on the iPad is empty

Check that the iPad and the computer are on the same network and that NDI output is on in OBS (step 2). If you tapped “Don't Allow” the first time, turn access on in iPad Settings → Apps → Overlay Pencil → Local Network. If sources still don't appear, close the app and open it again.

OBS doesn't see the “Overlay Pencil” source

Overlay Pencil has to be open on the iPad screen — iPadOS pauses sending in the background. Also check that the computer's firewall isn't blocking OBS on the local network.

The drawing layer has a black background in OBS

Set Latency Mode of that NDI source to Normal (step 5).

The drawing is offset from the picture

The layer and the picture must take up the same area in the OBS scene. Stretch the Overlay Pencil source to the full frame, like the picture under it.

The picture on the iPad stutters

A full 1080p picture from OBS needs tens of Mbit/s, and Wi-Fi shares that with the drawing layer. In this order, it helps to: connect the computer by cable, put the iPad on 5 GHz Wi-Fi, and set Incoming Video Quality to Low Bandwidth.

How do I pause or skip a video on my computer from the iPad?

Install the free Overlay Pencil Remote app for Mac and pair it in Settings → Computer Control. The playback buttons appear on the iPad once it's connected.
